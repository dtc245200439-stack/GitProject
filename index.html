Bài Thực Hành: Các Phương Pháp Nhúng CSS vào HTML

Phần 1: Inline Style (Nhúng trực tiếp vào thẻ HTML bằng thuộc tính style)

Tiêu đề sử dụng Inline CSS (Màu Tím)

Đây là đoạn văn bản được định dạng màu sắc trực tiếp bằng thuộc tính style="color: #db2777;".

Phần 2: Internal Style (Nhúng bằng thẻ <style> trong phần <head>)

Tiêu đề sử dụng Internal CSS (Màu Đỏ)

Đây là đoạn văn bản được định dạng bằng bộ chọn CSS định nghĩa trong thẻ <style>.

Phần 3: External Style (Nhúng tệp CSS bên ngoài qua thẻ <link>)

Tiêu đề sử dụng External CSS (Màu Xanh Dương)

Đây là đoạn văn bản được định dạng bởi tệp style.css liên kết từ bên ngoài.
